# Intake structure

Stage `intake-structure` of the **intake** model. 18 technology types are listed for this stage; none is built yet.

The full list, the calculations, the expert rules and the status of each type are in `core/library/wtp/` (see `docs/wtp/COVERAGE.md` and `docs/wtp/CALCULATIONS.md`).

Types:

- **Surface water intake:** River bank intake; River tower intake; River submerged intake; Floating intake; Canal intake; Reservoir multi-level intake; Lake crib intake; Jack-well intake
- **Groundwater intake:** Tube well; Dug well; Infiltration gallery; Collector (radial) well; Spring box; Bank filtration well
- **Seawater intake:** Open sea intake; Beach well intake; Sub-surface seawater gallery
- **Rainwater intake:** Roof rainwater harvesting

A type becomes a model page here (`parametric/*.html`, with the shared export kit) only after it has data, calculations and sources; see `docs/wtp/STRUCTURE.md`.
