# Screening and debris removal

Stage `screening` of the **intake** model. 8 technology types are listed for this stage; none is built yet.

The full list, the calculations, the expert rules and the status of each type are in `core/library/wtp/` (see `docs/wtp/COVERAGE.md` and `docs/wtp/CALCULATIONS.md`).

Types:

- **Coarse screening:** Trash rack; Coarse bar screen, manual cleaning; Coarse bar screen, mechanical cleaning
- **Fine screening:** Fixed fine screen; Traveling band screen; Drum screen; Microstrainer; Wedge-wire (fish) screen

A type becomes a model page here (`parametric/*.html`, with the shared export kit) only after it has data, calculations and sources; see `docs/wtp/STRUCTURE.md`.
