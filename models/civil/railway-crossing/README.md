# Railway Crossing Methods

One carrier pipe under a railway embankment. Pick the method; the casing, pits, cover rules, 3D model and drawings follow.

| Method | Casing / structure |
|---|---|
| Microtunnelling | RC jacking pipe, remote slurry machine |
| Pipe jacking (man-entry) | RC jacking pipe, ID 1.2 m and larger |
| Auger boring | steel casing, carrier on skids |
| Pipe ramming | steel casing, carrier on skids |
| Box jacking | RC box, carrier on saddles |
| Open cut | sheet-piled trench, temporary girders under each track |

HDD is a separate model (`models/civil/hdd-crossing`).

- Views: 3D, plan, long section A-A, cross section at ROW centre, typical detail, and a **Compare methods** table that checks every method against your inputs.
- Downloads: GLB, OBJ, STL, DXF 3DFACE, DXF sheet, SVG sheet, spec.json, or ZIP of all. Same formats and units as the HDD model.
- Casing sizes, pit sizes, length limits and cover factors are typical planning values, not a design. Confirm with the contractor, geotechnical report and railway authority.
- Not included: HDD here, tunnel boring, NATM, groundwater control design, settlement prediction, STEP / IFC / FBX / DWG.
