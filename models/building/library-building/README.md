# Library Building (2 storey, 2 shatak plot)

One page (`parametric/library-building.html`): complete 2 storey library on a 9.0 x 9.0 m plot (2 shatak = 80.9 m2).
Building 7.5 x 6.75 m (50.6 m2 per floor, 101 m2 total). Open the file in a browser (needs internet for three.js).

- Structure: pad footings, column necks, plinth beams, 3 x 3 column grid, floor and roof beams, slabs, dog-leg staircase.
- Envelope: brick walls, glazed main door, rear exit, 16 windows with sunshades, parapet, sign, entrance steps and canopy.
- Interior: reading hall with issue desk, book stacks, reading tables; first floor carrels and stacks; toilet.
- Site: boundary wall with gate, paved front yard, road.
- Every group can be switched ON/OFF. Cut height slider and the two plan buttons show the interior.
- Checks: column span, footing inside plot, clear height, stair riser, window area. Download GLB and spec.json.

Concept model only. Structural design, soil test and local approval are still needed.
