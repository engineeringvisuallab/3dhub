# Buildings and site works

Stage `buildings-and-site` of the **treatment-plant** model. 16 technology types are listed for this stage; none is built yet.

The full list, the calculations, the expert rules and the status of each type are in `core/library/wtp/` (see `docs/wtp/COVERAGE.md` and `docs/wtp/CALCULATIONS.md`).

Types:

- **Process buildings:** Filter gallery building; Chemical house; Pump house; Control room
- **Support buildings:** Laboratory; Administration building; Workshop and store; Guard house; Staff quarters
- **Site works:** Internal roads; Stormwater drainage; Boundary wall and gate; Fire protection; Site lighting; Landscaping; Security system

A type becomes a model page here (`parametric/*.html`, with the shared export kit) only after it has data, calculations and sources; see `docs/wtp/STRUCTURE.md`.
